Free FCC GROL Practice Test: Elements 1, 3 and 8

Free online practice exams for the FCC General Radiotelephone Operator License (GROL) and Radar Endorsement, built from the official FCC question pools (1044 questions). Each practice exam picks one question from every key topic, exactly like the real test: 24 questions for Element 1, 100 for Element 3 and 50 for Element 8.
